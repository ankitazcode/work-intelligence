# Installation Guide

## 1. Clone Repository

```bash
git clone https://github.com/ankitazcode/work-intelligence.git
```

## 2. Open Project

```bash
cd work-intelligence
```

---

# Frontend Setup

## Move to frontend

```bash
cd frontend
```

## Install dependencies

```bash
npm install
```

## Start frontend server

```bash
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

---

# Backend Setup

Open another terminal.

## Move to backend

```bash
cd backend
```

## Install dependencies

```bash
npm install
```

## Start backend server

```bash
npm run dev
```

Backend runs on:

```text
http://localhost:5000/tasks
```
